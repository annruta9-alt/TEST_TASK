# Задание стажировки №1: веб-сервис и база в Docker

## Что нужно было сделать

Переделать веб-сервис из тестового задания 2 так, чтобы он работал в Docker, причём **в двух отдельных контейнерах**:

- **web** — веб-сервер Apache (через mod_wsgi) с нашим Flask-сервисом для видео;
- **db** — база данных PostgreSQL (вместо SQLite).

Оба контейнера запускаются одной командой через Docker Compose. Данные и видео не пропадают после перезапуска.

## Что в папке (что за что отвечает)

| Файл | Для чего |
|------|----------|
| `Dockerfile` | рецепт сборки контейнера web: Ubuntu + Apache + mod_wsgi + Python + Flask |
| `docker-compose.yml` | описание двух контейнеров (web, db), двух томов для данных и проверки готовности базы |
| `web_service.py` | тот же сервис, но на PostgreSQL; настройки базы берёт из переменных окружения |
| `app.wsgi` | одна строка, по которой Apache находит Flask-приложение |
| `apache/video.conf` | настройка Apache: порт 80, связка с Flask, раздача видео из `/media/` |
| `docker-entrypoint.sh` | скрипт, которым контейнер запускает Apache |
| `requirements.txt` | Python-пакеты внутри контейнера (flask, psycopg2-binary) |
| `README.md` | краткая инструкция на английском (так просили в задании) |
| `.env.example` | пример файла с паролем базы (настоящий `.env` в git не кладут) |
| `.dockerignore`, `.gitignore` | служебные: что не копировать в образ и не коммитить |

## Что установить (один раз)

1. **Docker Desktop для Windows** (у вас уже стоит).
2. Если он пишет «WSL needs updating», в PowerShell от имени администратора выполните `wsl --update`, затем в окне Docker Desktop нажмите **Try Again**.
3. Запустите Docker Desktop и дождитесь, пока он покажет, что работает. Проверка:
   ```
   docker --version
   docker compose version
   ```

Больше ничего ставить не нужно: Apache, PostgreSQL и Python для сервиса находятся внутри контейнеров.

## Как запустить

1. Распакуйте архив, например в `C:\Users\Ann\Downloads\тестовое\internship1`.
2. Если у вас ещё запущен старый `python web_service.py` из задания 2, остановите его (`Ctrl+C` в его окне): он занимает порт 8000.
3. Откройте PowerShell в папке `internship1` (в VS Code: Terminal → New Terminal, затем `cd internship1`) и выполните:
   ```
   docker compose up --build
   ```
   Первая сборка занимает несколько минут: скачиваются образы Ubuntu и PostgreSQL.
4. Окно с запущенными контейнерами оставьте открытым. Остановить их можно через `Ctrl+C`.

## Что должно получиться

В консоли после сборки появятся строки примерно такого вида (порядок может отличаться):

```
db-1   | ... database system is ready to accept connections
web-1  | ... Apache/2.4.58 (Ubuntu) mod_wsgi/5.0.0 Python/3.12 configured -- resuming normal operations
```

Во втором окне PowerShell проверьте состояние:
```
docker compose ps
```
Оба контейнера должны быть в состоянии `healthy`.

Откройте в браузере `http://localhost:8000/health`. Должно быть `{"status":"ok"}`.

### Проверка по пунктам задания

**1. Загрузка видео** (подставьте путь к любому вашему `.webm`, например из папки `video` рекордера):
```
curl.exe -F "file=@C:\Users\Ann\Downloads\тестовое\video\Acme GmbH.webm" -F "company_name=ACME GmbH" http://localhost:8000/upload
```
Ответ: `{"company_name":"ACME GmbH","video_url":"http://localhost:8000/media/ACME_GmbH.webm"}`. Эту ссылку можно открыть в браузере, и видео проиграется.

**2. Поиск по названию компании:**
```
curl.exe "http://localhost:8000/get_video_url?company_name=ACME%20GmbH"
```
Для несуществующего названия вернётся ошибка 404.

**3. Данные сохраняются после перезапуска:**
```
docker compose down
docker compose up
curl.exe "http://localhost:8000/get_video_url?company_name=ACME%20GmbH"
```
Ссылка снова вернётся, видео откроется. (`docker compose down -v` удаляет тома, то есть стирает данные.)

**4. Веб-часть ждёт базу.** Она стартует только когда база готова: `web` зависит от `db` с проверкой готовности, а ещё сам сервис повторяет подключение до 60 секунд. Поэтому падения при запуске быть не должно.

**5. Рекордер работает как раньше**, просто за адресом теперь Docker:
```
python capture_video.py --server http://127.0.0.1:8000 --view-seconds 10
```

## Полезные команды

```
docker compose logs -f web        # логи Apache и сервиса
docker compose exec web curl http://localhost/health
docker compose exec db psql -U video_user -d videos -c "select * from videos"   # записи в PostgreSQL
```

## Пароль базы

По заданию пароль указан прямо в `docker-compose.yml` (`video_pass`). Для настоящего проекта скопируйте `.env.example` в `.env`, впишите свой пароль и не коммитьте `.env` в git. Если смените пароль, выполните один раз `docker compose down -v`: PostgreSQL запоминает пароль при первом создании тома.

## Что делать, если не запускается

- **«port is already allocated» / порт 8000 занят**: остановите старый сервис или поменяйте `8000:80` в `docker-compose.yml`, например на `8080:80`.
- **«Cannot connect to the Docker daemon»**: Docker Desktop не запущен.
- **Другие ошибки**: пришлите текст из консоли.
